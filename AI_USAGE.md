# AI-assisted development

The participant used Codex to research public specifications and adjacent
projects, implement the MoonBit core, design regression tests and independent
reference adapters, draft documentation and configure CI. The participant is
responsible for reviewing the scope, implementation and submission materials.

Quality claims are limited to executable tests and the recorded targets and
versions. Production MoonBit, handwritten tests, generated test vectors and
vendored Go reference code are counted separately. The work does not claim that
AI-generated code is automatically correct or that no similar project can exist.

This repository's documentation is not presented as the participant's manually
authored one-page contest proposal. That proposal must be written and checked by
the participant according to the contest rules before submission.
